## 已通过

- Dashboard：7 天和 30 天周期可切换，页面无错误 Alert，1280px 无横向溢出。
- 预警穿透：点击“查看分析”进入目标项目，自动展开风险检查器和 PDF。
- 项目中心：搜索“银行”只保留对应项目；高风险筛选可正常更新列表。
- 项目对比入口：可连续加入两个项目；取消后选择数回到 1，“开始对比”按预期禁用。

- 接口：`/`、`/api/health`、`/api/files`、`/api/dashboard?days=7` 和 `days=30` 均返回 HTTP 200；历史项目数为 4。
- 报告：风险报告和项目对比报告在独立临时目录生成，文件大小分别约 35KB 和 39KB；均能由 Word 解析库重新打开。验证后只清理了本批次临时文件。
- 安全降级：临时无 Key 环境调用 DeepSeek 客户端时抛出受控 `RuntimeError`，未泄露 Key，非 AI 接口仍可用。
