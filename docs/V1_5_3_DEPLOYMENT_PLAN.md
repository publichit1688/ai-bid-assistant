## 部署前硬门禁

- 固定目标必须是已签署并完成云端候选门禁的正式提交，不跟随浮动 `main`。
- 校验Git bundle SHA-256、bundle引用、提交父链、版本和标签解引用身份。
- 云端正式工作区必须无已跟踪修改；记录旧HEAD、版本、服务、计划任务、监听端口和磁盘空间。
- 对SQLite、上传目录、报告目录、生产配置及旧前端dist执行不覆盖备份，并生成逐文件哈希清单。
- 本补丁无数据库迁移；若检查发现迁移差异，立即停止并重新评估。
- 不读取或输出API Key、共享鉴权令牌和真实文档内容。

## 建议部署步骤

1. 在独立临时目录导入固定bundle，验证提交和标签身份。
2. 使用隔离依赖/缓存运行完整后端回归、秘密扫描、依赖审计和前端lint/build。
3. 对正式运行数据及旧dist创建可验证备份；备份失败立即停止，正式目录不变。
4. 只切换代码和前端构建产物，保留生产 `.env`、SQLite、上传、报告和Caddy/Tailscale配置。
5. 保持FastAPI和Caddy仅回环监听，禁止新增腾讯云公网端口或安全组规则。
6. 启动后验证版本、健康/就绪、匿名401、代理鉴权、首页、固定入口JS和项目列表契约。
7. 使用保留合成项目验证报告导出、连续章节编号、PDF/Word预览、高亮、Dashboard穿透及项目对比。
