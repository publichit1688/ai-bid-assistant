# V1 鉴权方案决策

状态：用户已选择方案A；后端保护和前端凭据接入已实现，隔离共享模式全链路回归待完成。本地默认仍关闭鉴权。

## 已核对的现状

- 前端在 `App.jsx` 中分散使用绝对地址调用后端，尚无统一Axios实例或凭据注入点。
- PDF及Word转换预览通过 `/uploads/...` 直接加载；只保护 `/api` 会继续暴露客户文件。
- 报告接口返回二进制下载，鉴权失败必须继续使用统一JSON错误，成功时保持文件响应。
- FastAPI默认还会提供 `/docs`、`/redoc` 和 `/openapi.json`，生产环境需要关闭或纳入保护。
- 当前没有用户表、密码哈希、登录页、会话、角色、审计主体或数据库迁移机制。

## 方案A：单部署共享访问密钥

适用：V1单企业、小团队、单一信任域、优先快速封闭公网访问。

设计建议：

- 后端从秘密管理读取单个随机高强度访问密钥，只保存于进程环境或未提交的 `.env`。
- 客户端使用 `Authorization: Bearer ...`；后端常量时间比较，日志永不记录Header。
- `AUTH_MODE=disabled|shared_token`，本地默认 `disabled`；生产明确启用后，缺少密钥应拒绝启动。
- 前端增加一次会话输入，凭据仅保存在内存；刷新后重新输入。V1不放入源码、构建变量、URL、localStorage或日志。
- 建立统一Axios实例，为API、报告下载和PDF.js请求注入Header；`/uploads/*`同样保护。
- 401统一返回 `AUTH_REQUIRED`，错误响应仍携带请求ID。
- 删除权限无法区分个人；共享密钥泄露后必须整体轮换，也不能形成个人审计。

优点：改动较小、无需用户表和数据库迁移、适合单机V1。
缺点：所有使用者权限相同、无法撤销单个人、共享和审计能力有限。

## 方案B：账号、会话与角色权限

适用：多人协作、需要个人审计、查看/编辑/管理分权或未来对外SaaS。

设计建议：

- 新增用户、角色、会话/刷新令牌和审计主体数据模型，需要正式数据库迁移与备份。
- 密码必须使用成熟密码哈希；会话建议使用 `HttpOnly`、`Secure`、适当`SameSite` Cookie，并设计CSRF防护。
- 初始角色至少为查看者、编辑者、管理员，对应上方保护矩阵。
- 增加登录、退出、会话续期、禁用用户、密钥轮换和登录限流。
- 前端增加登录态、401统一处理和角色控制；后端权限仍是最终边界，不能只隐藏按钮。
- 静态原件改为经过鉴权的文件接口，或确保静态挂载也受同一会话中间件保护。

优点：可撤销单人、可审计、可最小权限扩展。
缺点：涉及数据库迁移、登录UI、Cookie/CSRF、账号生命周期和更多安全回归，不适合作为一个自动小批直接启用。

## 方案C：外部网关或企业SSO

适用：已有企业身份平台、VPN、Cloudflare Access、OIDC反向代理或统一网关。

应用只信任固定代理注入且不可被外部直连伪造的身份Header；后端端口必须限制为代理可达。该方案依赖实际平台，不能仅凭本仓库模板假设安全。

## 已确认决策

用户于2026-09-02选择方案A。保持 `AUTH_MODE=disabled` 作为开发默认值；生产启用共享密钥。方案A不提供个人权限或个人审计，未来若转为多人分权或对外SaaS，应进入独立的方案B迁移，不在V1中叠加。

## 方案A实施批次与验收

1. 后端鉴权中间件、启动配置检查、401契约和公开路径白名单。
2. 前端统一API客户端、内存凭据输入、401状态和PDF/报告带Header。
3. 回归项目中心、Dashboard、上传、风险定位、对比、报告、删除和静态原件保护。
4. 类生产环境验证未授权无法读原件，授权后全部受保护功能可用。

回滚：将 `AUTH_MODE` 恢复为 `disabled` 并重启即可回到当前开发行为；生产不得以此作为长期故障绕过，回滚必须同时限制网络入口。

## 方案B实施批次与验收

先备份数据库并建立迁移脚本，再分批实现用户模型、服务端会话、角色依赖、登录UI、静态文件保护和审计事件。回滚必须能恢复迁移前数据库，不能只删除前端登录页。

## 当前实现

- 后端已加入共享密钥中间件：仅 `/`、`/api/health` 和CORS预检公开，其余API、`/uploads/*`、就绪探针及未知路由均受保护。
- 共享模式使用Bearer凭据和常量时间比较；缺失或错误凭据返回稳定的 `401 / AUTH_REQUIRED`，配置无效则失败关闭并返回 `503 / AUTH_NOT_CONFIGURED`。
- 启动检查新增 `auth_configuration`；共享模式要求 `APP_ACCESS_TOKEN` 至少32位，错误信息不包含密钥。
- 共享模式关闭FastAPI的 `/docs`、`/redoc` 和 `/openapi.json`；开发默认 `AUTH_MODE=disabled`，因此现有前端行为不变。
- 前端已使用统一Axios客户端和仅内存凭据输入；PDF及Word转换PDF通过带Header的Blob请求加载，两类报告与普通API共享凭据。生产不得在完成隔离共享模式全链路回归前开启。
