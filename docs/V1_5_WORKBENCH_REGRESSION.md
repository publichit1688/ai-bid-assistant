# V1.5 智能编标工作台浏览器回归

日期：2026-09-04

## 隔离边界

- 使用 `backend/scripts/prepare_auth_regression.py` 创建全新纯合成 SQLite、PDF 占位文件和工作台数据。
- 后端数据库、上传和报告目录全部指向本批临时目录，不读取用户数据库或上传文件。
- 进程设置非空测试 Key，并将模型地址指向不可达的 `127.0.0.1:9`；AI入口只展开确认提示后取消。
- 回归结束后前后端正常停止，8000和5173端口确认关闭，临时目录删除。

## 浏览器结果

- 未选择项目时展示明确空状态，AI与刷新入口禁用。
- 选择合成PDF项目后正确显示修订1、一个待审核目录、一个待审核评分点和来源引用。
- “生成目录建议”确认框明确说明会发送当前文件、消耗模型额度且结果仅为待审核建议；点击取消后没有发起工作台AI请求。
- 接受目录和评分点建议后修订依次更新为2、3，状态变为已确认。
- 人工映射保存后修订更新为4，已覆盖评分点由0更新为1，缺口由2更新为1。
- 新增响应材料后修订更新为5，名称、责任人、说明和待准备状态正确展示。
- 将材料编辑为阻塞后修订更新为6，阻塞材料汇总由0更新为1。
- 切换到合成Word项目显示独立空工作台和禁用的材料新增按钮；切回PDF项目后修订6及全部结果保持。
- 1024×768视口下文档宽度等于视口宽度，工作台和三栏内容没有横向溢出。

## 已知提醒

- 浏览器控制台仅出现既有Ant Design `List` 弃用提醒，不影响本次操作。
- Dashboard首次加载尝试生成管理摘要，但请求只命中不可达的本机测试地址并安全返回502；未连接真实模型。

## 结论

目录建议、评分点审核、章节映射、响应材料和修订统计形成可审计的前后端最小闭环；未发现阻塞P5-05的问题。
