# 百度 OCR 配置与安全说明

项目仅在 PDF 页面缺少有效文字层时调用百度通用文字识别（标准含位置版）；普通电子 PDF、DOCX 和 DOC 不发送给百度 OCR。

配置以仓库根目录 `.env` 为准；若历史 `backend/.env` 中对应 OCR 变量为空，后端会自动回退读取根目录配置，避免空文件遮蔽已填写的凭据。

## 本机配置

1. 在百度智能云文字识别控制台创建应用并开通“通用文字识别（标准含位置版）”。
2. 将仓库根目录 `.env.example` 复制为 `.env`，只在本机填写：

```dotenv
OCR_PROVIDER=baidu
BAIDU_OCR_API_KEY=你的API Key
BAIDU_OCR_SECRET_KEY=你的Secret Key
```

不要把真实凭据粘贴到聊天、源码、测试、截图或提交记录中。`.env` 已被 Git 忽略。

## 默认保护

- `OCR_PROVIDER=disabled`：默认关闭，避免文件意外发送第三方。
- `OCR_MIN_TEXT_CHARS=20`：页面去除空白后少于20字符才触发 OCR。
- `OCR_MAX_PAGES=50`：一次上传最多调用50个扫描页；超过时在任何 OCR 请求前中止。
- 页面在本地渲染为最长边不超过4096px的 JPEG，再以 Base64 表单提交。
- OCR 图片 Base64 超过6MB时在本地拒绝，给官方8MB编码后上限保留余量。
- Access Token 只保存在后端进程内存并按有效期缓存，不写数据库或日志。

## 当前边界

- 当前默认接入标准含位置版文本识别，不做表格结构还原、印章识别和手写专项识别。
- OCR 行坐标按识别图片尺寸归一化并写入风险结果；重新分析后的扫描 PDF 可在响应式预览上叠加风险高亮框。
- 百度 OCR 可能产生费用并处理上传的扫描页。启用前应确认客户授权、百度账号额度和数据合规要求。
- 真实服务验收必须使用已授权且脱敏的扫描 PDF，原件和识别正文不得提交 Git。

官方接口入口：https://cloud.baidu.com/doc/OCR/index.html
