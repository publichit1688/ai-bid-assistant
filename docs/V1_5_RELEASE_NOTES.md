# AI标书助手 V1.5.0 正式版说明

版本：`1.5.0`

状态：已由签署候选提升为正式版本；创建本地发布提交和 `v1.5.0` 标签，不推送、不部署。

## 核心新增

- 新增独立智能编标工作台，关联现有招标项目且不破坏V1分析数据。
- 从招标文件生成带页码和原文引用的目录建议，验证失败的来源不会写入。
- 结构化提取带来源的评分点和最高分值，结果默认待人工审核。
- 支持目录与评分点的人工接受、拒绝及完整修订快照。
- 支持已确认评分点到已确认章节的人工映射，并展示覆盖与缺口统计。
- 支持响应材料的人工新增、责任人、说明和待准备/进行中/已完成/阻塞状态。
- 前端提供明确AI调用确认，说明当前文件会发送给已配置模型且消耗额度。

## 安全与数据边界

- 使用两版显式、可重复的SQLite增量迁移，不删除或覆盖V1表和历史数据。
- 同名表结构残缺时拒绝登记迁移成功；当前迁移仅支持SQLite。
- 所有写操作携带工作台修订号，过期写入返回409并阻止覆盖新状态。
- AI输出只有来源可验证的项目才会保存，保存后仍需人工确认。
- `.env`、数据库、上传文件、报告和真实样本不进入候选提交。

## 明确不包含

- 一键生成整本投标文件。
- 自动生成或补写标书正文。
- 自动分派责任人或自动提交投标。
- 复杂目录树拖拽编辑。

## 已知提醒

- 前端主包约2.46 MB，仍有拆包提醒。
- Ant Design `List` 组件存在下一主版本弃用提醒。
- 当前Windows环境无法执行符号链接测试，该用例保持跳过。
- 工作台AI建议质量仍依赖招标文件文字质量和人工审核。
