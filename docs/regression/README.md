# 真实标书回归样本治理

本目录只保存脱敏台账、空白预期模板和回归结果模板，不保存 PDF/DOCX 原件、截图、数据库、报告或个人信息。

## 本地目录

真实样本只能在确认授权后，由用户自行放入仓库根目录下的 `regression_samples/`。该目录已被 Git 忽略。自动开发不得从 `backend/uploads/` 擅自复制既有文件，也不得把本地绝对路径写入可提交台账。

建议本地结构：

```text
regression_samples/
  RB-PDF-TEXT-SHORT/
    source.pdf
    expected.local.json
  RB-DOCX-TEXT/
    source.docx
    expected.local.json
```

## 执行门槛

一个样本必须同时满足以下条件才可执行：

1. `SAMPLE_REGISTRY.csv` 中授权状态为“已确认”。
2. 原件不包含未脱敏的姓名、电话、身份证号、账号、签名、印章或商业秘密；无法脱敏时必须有明确受控测试授权。
3. 本地存在基于 `EXPECTED_RESULT.template.json` 创建的 `expected.local.json`。
4. 测试范围、模型调用费用和是否允许写入隔离数据库已经确认。

授权为“待确认”“已撤销”或“禁止使用”的样本不得运行。

## 工作流

1. 在台账选择覆盖槽位，只更新脱敏元数据，不填真实文件名和绝对路径。
2. 用户确认授权后，将状态改为“已确认”，原件放入本地忽略目录。
3. 复制预期模板为本地 `expected.local.json`，填写允许公开的脱敏预期。
4. 在隔离数据库和隔离报告目录执行测试，记录模型、日期和结果。
5. 只把脱敏后的结果摘要复制到 `REGRESSION_RESULT.template.md` 的副本；失败证据必须最小化。
6. 测试后不自动删除用户原件；如需清理，必须由用户明确授权并指定准确路径。

## 预期容差

- 项目名称、招标单位、日期、金额等结构化字段应使用精确或明确的脱敏预期。
- 风险页码允许在模板中配置容差，默认0页；扫描件应单独说明 OCR 页码限制。
- 风险文本使用脱敏关键词或短哈希，不复制长段招标文件原文。
- AI建议不做逐字匹配，只检查必含主题、禁止虚构主题和结构完整性。
