# AI标书助手 V1.0.0 发布说明

版本：`1.0.0`
发布日期：2026-09-03
状态：本地正式版本；已授权创建本地 `v1.0.0` 标签，尚未推送或部署到真实服务器。

## 主要能力

- PDF、DOCX和DOC招标文件分析，Word文档通过Microsoft Word优先、WPS备用转换为真实分页PDF预览。
- 风险分级、评分、扣分依据、原文页码定位、电子PDF文字高亮及扫描PDF OCR坐标框。
- Dashboard管理预警、项目中心、风险检查器、项目对比、风险报告和对比报告导出。
- Dashboard AI摘要缓存、统一数据契约、事务化上传和明确的AI/解析错误响应。
- 共享密钥鉴权、限流、结构化脱敏日志、文件/路径校验、生产启动检查及安全备份恢复。

## 验证摘要

- 真实回归覆盖6份授权业务文档、216页和35项风险；35/35页码有效，34/35具备可验证高亮或OCR坐标。
- 当前自动回归基线为后端138项通过、1项因Windows符号链接权限跳过；前端lint/build通过，Python/npm依赖审计均无已知漏洞。
- Python当前环境及前端生产依赖最近一次联网审计均为0个已知漏洞；秘密扫描通过。

## 已知限制

- 扫描件只有在显式配置百度OCR并具备授权时才会发送缺少文字层的页面；无可靠原文匹配的风险不会强行绘制高亮框。
- AI引用和关键词不保证与原文逐字一致，可靠定位仍以页码、连续原文片段和OCR坐标为准。
- 当前本机实际验证引擎为WPS；Microsoft Word分页一致性、加密文件、早期Word格式和复杂嵌入对象未全面验证。
- 复杂表格回归已覆盖合并单元格，但未覆盖所有跨页嵌套表格组合。
- 当前限流为单进程内存实现，多实例部署需要可信网关或共享限流设施。
- 前端生产包仍有约2.44 MB主包提醒，Ant Design `List`存在未来主版本迁移提醒。
- V1提供招标文件分析与风险辅助，不替代专业人员审核，不包含一键生成整本投标文件。
- 正式服务器模板、证书、账号权限和真实持久化目录仍需部署人员按目标环境审核。

## 升级与回滚

候选验收、自动检查和本地版本冻结已经完成。真实服务器部署前仍须按照 `docs/V1_RELEASE_CHECKLIST.md` 完成目标环境配置、当次隔离备份恢复和部署后抽查。回滚不得删除或原位覆盖用户数据库、上传件及报告。
