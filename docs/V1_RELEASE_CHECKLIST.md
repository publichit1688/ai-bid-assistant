## 自动检查

在仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\verify_release.ps1
```

该入口依次执行Python编译、完整后端pytest、秘密扫描、Python依赖审计、前端lint/build和npm生产依赖审计。依赖审计需要联网，任何一步失败都必须停止发布。
