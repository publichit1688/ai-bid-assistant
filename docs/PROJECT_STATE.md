## 已确认实现

- 后端为 FastAPI，使用 SQLite/SQLAlchemy 保存标书、分析结果和 Dashboard AI 摘要缓存。
- 前端为 React/Vite，主要 UI 使用 Ant Design，图表使用 ECharts。
- 已存在上传分析、历史文件/项目中心、风险检查器、风险定位高亮、响应式 PDF 区域、Dashboard 预警穿透、项目对比、风险报告及对比报告导出。
- DOCX/DOC 不再使用按字符模拟分页：默认由 Microsoft Word 转换为 PDF，Word 不可用或转换失败时自动回退 WPS Office；分析、预览和风险定位共用转换后的真实页面。
- Word 预览接口返回转换 PDF 的真实页数、实际渲染引擎和历史风险页码映射；前端每页下方显示“第 X 页 / 共 Y 页”，历史模拟页码会按原文命中重新映射到渲染页。
- 本机已安装并自动发现 WPS Office x64 12.1.0.28488；两页合成 DOCX、三页本地 Word 报告、61页历史 DOCX 和64页历史 DOC 均已完成真实转换验证，界面页码、下一页、风险跳页和文字层高亮通过本地浏览器检查。
- 扫描 PDF 默认接入百度通用文字识别（标准含位置版）：先本地检测文字层，仅将缺少有效文字的页面提交 OCR，保留原 PDF 页码，并将命中文字坐标叠加为响应式风险高亮框。
- Dashboard AI 管理摘要具备前端缓存逻辑，后端存在 `dashboard_ai_cache` 持久化模型及接口逻辑。
- 前端生产构建可完成。
- 前端 ESLint 已清零，Dashboard 与标书分析入口已完成本地浏览器渲染抽查。
- 已移除 Vite 示例全局样式，统一页面背景、Content 间距与内容最大宽度；PDF 会根据中央容器实际宽度在 700px 上限内动态缩放。
- Dashboard、标书分析和项目对比的顶层标题已统一层级、Ant Design 图标、卡片圆角与垂直间距。
- 项目中心、Dashboard、风险检查器和项目对比已统一加载、错误和空状态；项目列表与 Dashboard 请求失败会保留 toast 并显示页面内 Alert。
- 已完成 1024/1280/1440/1920px 桌面响应式矩阵：窄桌面侧栏收窄、Header 压缩、Dashboard 图表单列稳定显示，Content、PDF 和项目对比入口无横向溢出。
- 已完成 V1 受保护功能 UI 回归：Dashboard 周期与预警穿透、项目中心搜索/筛选、风险定位高亮、项目选择/取消对比和报告生成均通过；详细证据见 `docs/V1_UI_REGRESSION.md`。
